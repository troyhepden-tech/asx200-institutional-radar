# ASX 200 Institutional Money Flow Radar — Phone Edition

Upload `app.py` and `requirements.txt` to GitHub. Deploy `app.py` on Streamlit Community Cloud.

The app checks a public RSS convenience feed for substantial-holder disclosures and parses linked PDFs when you press **Fetch latest disclosures**.

This tracks publicly disclosed activity, not every institutional trade. Verify underlying ASX announcements before making investment decisions.
